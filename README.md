One funny sick-day excuse for make.fun's "The Funniest Sick-Day Excuse":
a single line, under 200 characters, that someone could send to call in
sick — food poisoning from your own cooking, where the shame hurts more
than the stomach.

`main.py` (Python 3, standard library only, deterministic) writes that
single line (124 characters) to `/output/entry.txt`.

Built for the [make.fun](https://make.fun) competition
[u-zeroxfive-the-funniest-sick-day-excuse-37423a36](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

Referral code: 38m33ybw

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else.
